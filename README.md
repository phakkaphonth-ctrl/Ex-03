---

```
test-app1/
├── index.html    # โครงสร้างหน้าเว็บ (จุดที่ต้องแก้ไข 1–10)

```

---

## สิ่งที่ต้องทำ

ภายในโค้ดมีคอมเมนต์กำกับไว้ทั้งหมด **12 จุด** ในรูปแบบ

```
===== แก้ไขจุดที่ N : คำอธิบาย =====
```

ให้แก้ไขข้อมูลทุกจุดให้เป็นข้อมูลจริงของตนเอง โดยมีเงื่อนไขดังนี้

1. ต้องแก้ไขให้ครบทั้ง 12 จุด
2. ห้ามมีข้อมูลตัวอย่างเดิมหลงเหลืออยู่ เช่น `XX`, `000000000000`, `ตัวอย่าง นักศึกษา`, `your-username`
3. เมื่อแก้ไขเสร็จแล้ว ให้ลบบรรทัดคอมเมนต์กำกับงานออกให้หมด
4. หน้าเว็บต้องยังแสดงผลได้ถูกต้องหลังแก้ไข
